## 表示する情報

| 分野 | 情報源 | 更新 |
|------|--------|------|
| 感染症 | WHO 疾病発生ニュース | 1日2回（朝・夕方）、決まった時刻に自動（AI不使用） |
| 研究と対策 | 査読論文・公的機関・国際機関（AIを活用した研究を含む）、セキュリティ更新・防災・防犯の公式の対策、NASA・NIHの報道発表の見出し | 見出しは1日2回自動（AI不使用）、ほかは原典を確認して不定期に掲載 |
| こころと福祉 | 公的機関の統計・相談窓口、公的機関・国際機関の報告書 | 原典を確認して不定期に掲載 |
| ITセキュリティ | 米国 CISA の悪用が確認された脆弱性、JPCERT/CC の注意喚起、IPA の重要なセキュリティ情報 | 1日2回（朝・夕方）、決まった時刻に自動（AI不使用） |
| 防犯 | 公的機関の詐欺・闇バイトなど犯罪の注意喚起と統計、金融庁（注意喚起のみ）・米FTC・英国NCSCの新着の見出し | 見出しは1日2回自動（AI不使用）、ほかは原典を確認して不定期に掲載 |
| 防災 | 公的機関が公表した災害の被害状況、総務省消防庁の災害情報の見出し | 見出しは1日2回自動（AI不使用）、ほかは原典を確認して不定期に掲載 |
| 地震 | 米国地質調査所（USGS）の地震情報（M5.5以上） | 1日2回自動（AI不使用） |

各分野の表示はおおむね20〜50件（今日の動物たちは毎日20件）（足りないときに情報を作って埋めることはしない）。このサイトは緊急時の情報源ではありません。

## 主な機能

- ゆっくり回る地球儀。ドラッグ・ホイール・2本指で操作。国・地域の検索と「現在地」で移動
- 日本語／英語の表示切り替え（URL の `?lang=en`。設定は保存しない）
- 地域を選んだまま、ほかの分野へ切り替え
- 昼夜の境界と、日の出・日の入り前後の帯を表示（日時からの計算のみ）
- 同じ地域・話題の古い情報は、公表日から7日間「以前の情報」と明示して表示
- iPhone・iPad・Android・パソコンに対応

## 安全設計の要点

- サーバー・ログイン・フォーム・APIキー・Cookie・アクセス解析なしの静的サイト
- 自動取得は決まったプログラムだけで行い、**外部の文章を生成AIに読ませない**
- 自動更新はリポジトリに書き込まない。主な取得元（WHO・CISA）の取得や検査に失敗したら公開を止め、前回の内容を残す。補助の取得元（USGS・JPCERT/CC・IPA・各機関の見出し）だけの失敗では公開を続け、画面に取得できなかった取得元を表示する
- AI・bot が変更できるのは2ファイルだけ（CI が強制）。書く者と監査する者を分け、運用者が最後に承認
- 個人情報・秘密情報の混入を CI が検査。サイトを見るだけでは閲覧者の個人情報は取得しない（ご意見フォームの送信内容とメールアドレスを除く）
- npm の外部パッケージを使わず、GitHub Actions はコミットSHAで固定

詳しくは [docs/SECURITY-DESIGN.md](docs/SECURITY-DESIGN.md)。

## ローカルで確認

Node.js 22 以上が必要です。外部パッケージのインストールは不要です。

```bash
node scripts/build.mjs --offline  # ネット接続なしで組み立て（自動取得の分野は「未取得」と表示）
node scripts/serve.mjs            # http://127.0.0.1:8080/
```

## フォルダ構成

```
AGENTS.md         AI・bot が最初に読むルール
ops/              運用手順書（役割・時刻・掲載・監査・攻撃対策・個人情報）
data/curated/     掲載内容（entries.json）と更新履歴（changelog.json）…AI・botが変更できるのはこの2つだけ
data/directory/   国・分野別の公式リンク集（links.json）…運用者だけが管理（AI・botは変更しない）
scripts/          取得・検査・組み立て（外部パッケージなし）
site/             画面（HTML/CSS/JS、地図データ、同梱ライブラリ、日英の言語ファイル）
.github/          ワークフロー（毎日の取得と公開／PR検査）、CODEOWNERS、PRテンプレート
.githooks/        コミット前の自動検査（任意）
docs/             安全設計・GitHub設定・運用手順・情報源メモ
```
